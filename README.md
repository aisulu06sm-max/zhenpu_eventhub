# EventHub - Event Management Platform

## About the Project

EventHub is a web application designed to help
users discover events, view event details and
register for different activities.

The platform provides an easy way to manage
events and user registrations.

## Project Purpose

The purpose of this project is to develop
an event management platform using PHP
and MySQL.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Bootstrap
- GitHub

## Main Features

- User registration and login
- View all events
- Search events
- Filter events by category
- View event details
- Register for events
- Manage personal registrations
- Add, edit and delete events
- Admin dashboard

## Database Structure

The project uses MySQL with five tables:

1. users
2. categories
3. events
4. registrations
5. favorites

## Main Pages

- Home page
- Events page
- Event details page
- Registration page
- Login page
- User profile
- My events
- Admin dashboard
- Add event page
